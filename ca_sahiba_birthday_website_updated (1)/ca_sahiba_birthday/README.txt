CA SAHIBA BIRTHDAY WEBSITE

FLOW: index.html (archery opening) -> cake.html (cake cutting) -> home.html (birthday homepage)

HOW TO TEST:
1. Keep all HTML files, style.css, and script.js together in this folder.
2. Double-click index.html to open it in Chrome.
3. Click the arrow to go to the cake page.
4. Click Blow out the candles, then drag the knife across the cake or press Cut the Cake.
5. After the reveal, click Continue to Your Birthday Surprise.

PERSONAL PHOTO:
Add her picture as photos/ca-sahiba.jpg.
For the memories gallery, add photos/memory1.jpg, memory2.jpg, and memory3.jpg.

GITHUB PAGES:
Upload every file and the photos folder to the same repository. The site's published URL should end with /index.html or the repository root. Ensure all files are committed.

This is a stylized animated web cake, not a physical or photorealistic simulation.
